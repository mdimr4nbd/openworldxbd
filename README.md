# Openworldxbd — Official Digital Portfolio & Connect

Ultra-lightweight, mobile-first single-file web application engineered for zero-lag transitions and instant Vercel deployment.

## Included Files
- `index.html`: Complete self-contained HTML5, CSS3, and Vanilla JS application.
- `vercel.json`: Clean static deployment configuration for Vercel.

## Quick Customization
Open `index.html` and replace the placeholder social URLs (`wa.me/966500000000`, `m.me/openworldxbd`, `t.me/openworldxbd`) with your official handles.
